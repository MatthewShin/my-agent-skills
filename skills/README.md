# Skill 디렉터리

각 Skill은 `skills/<skill-name>/SKILL.md` 형태로 추가한다. 디렉터리 이름과 `SKILL.md`의 `name` 값은 같아야 하며, 이름에는 소문자 영문자, 숫자, 하이픈만 사용한다.

새로 추가하는 Skill에는 `tomato-` 접두사를 붙인다. 현재 마인드맵 Skill은 `tomato-create-mindmap`, 프로젝트 구조 HTML Skill은 `tomato-project-structure-html`이다.

이 파일 자체는 Skill이 아니며 `skill-manager`의 설치 대상에 포함되지 않는다.
