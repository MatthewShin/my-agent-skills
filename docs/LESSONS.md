# 학습 기록

- Codex 사용자 전역 Skill 기본 경로는 이 프로젝트에서 `~/.codex/skills/`로 취급한다. 제품 경로를 추정하지 말고 프로젝트 요구사항과 사용자 확인을 우선한다.
- 사용자가 Skill 이름을 지정하거나 변경하면 디렉터리명, `SKILL.md`의 `name`, 작업 문서와 저장소 내 참조를 함께 검색해 동일한 이름으로 맞춘다.
- 새로 만들거나 저장소로 가져온 Skill의 이름에는 `tomato-` 접두사를 사용한다.
- 작업 관리 문서의 경로와 대소문자는 운영 규칙에 적힌 `tasks/TODO.md`, `docs/LESSONS.md`, `docs/COMPLETE.md`를 그대로 사용한다.
