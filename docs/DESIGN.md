# 설계 원칙

## 목표

Skill은 여러 Agent 제품에서 같은 원본을 안전하게 재사용할 수 있어야 한다. 저장소 구조와 문서는 새로운 Skill을 쉽게 추가하고 기존 Skill을 예측 가능하게 관리하도록 돕는다.

## 원칙

- **단일 원본:** Skill 내용을 제품별 경로에 복사하지 않고 symbolic link로 공유한다.
- **제품 독립성:** 공통 절차는 특정 Agent 제품의 기능에 종속되지 않게 작성한다.
- **명시적 진입점:** 모든 Skill은 `SKILL.md`에서 사용 조건과 작업 절차를 설명한다.
- **안전한 설치:** 기존 파일이나 다른 링크를 자동으로 덮어쓰거나 삭제하지 않는다.
- **반복 가능성:** 설치 명령을 여러 번 실행해도 같은 상태를 유지한다.
- **최소 구성:** 보조 디렉터리와 외부 의존성은 필요성이 확인될 때만 추가한다.

## 문서 책임

- `AGENTS.md`: 반드시 지켜야 할 프로젝트 운영 규칙
- `ARCHITECTURE.md`: 구성 요소와 설치 흐름
- `CONVENTIONS.md`: 작성·구현·Git 규칙
- `VERIFICATION.md`: 완료를 입증하는 검사 방법
- `DESIGN.md`: 구조와 동작을 결정하는 설계 기준
- `LESSONS.md`: 재발 방지를 위한 학습 내용
- `COMPLETE.md`: 완료된 작업의 간단한 이력
